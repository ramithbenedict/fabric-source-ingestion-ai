### Environment suffixes
Environment suffixes are applied to the workspace but NOT on the items inside the workspace, since items can be promoted across environments while keeping the same name.

| Suffix | Meaning |
| --- | --- |
| `DEV` | Development |
| `UAT` | User acceptance testing |
| `PRD` | Production |
